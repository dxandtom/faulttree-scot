# FaultTree-SCOT

网络保障(CS)场景下的智能根因分析工具:基于**故障树规则**与**实际数据**,自动生成并执行 **SCOT** 诊断计划。

## 概览

整个流程由三个 skill 协作完成:

1. **生成 SCOT** — 根据故障树规则与数据,生成数据解析脚本,并编排出一个多步骤的 SCOT 诊断计划(逐步解析各类数据 → 综合根因分析)。
2. **执行 SCOT** — 按 SCOT 计划逐步执行,在分析步骤调用根因分析规则。
3. **根因分析规则** — 一套 prompt 规则,供执行阶段做综合根因分析时调用。
