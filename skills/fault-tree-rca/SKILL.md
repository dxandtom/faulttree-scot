# fault-tree-rca —— 综合根因分析

**本文件已加载,不要再次加载或调用本技能;"加载"≠"完成",真正产出根因 JSON 才算完成。** 现在立刻依据 `result/rca_input.json` 和下文规则产出根因、写到 `result/rca.json`。

诊断链路的最后一步:把"各指标已经解析好的结果"和"故障子树"放在一起,判定根因。

## 上游喂给你什么(输入契约)
通常由 `cs-scot-execute` 汇总在 `result/rca_input.json` 里:
- **`fault_tree_md`**:故障子树正文。`#/##/###` 表层级;每个标题下面跟着该节点的判断条件正文。**由人工编写,可能不规整、有跳跃或笔误。**
- **`indicator_results`**:dict,键是指标名(`kpi` / `chr` / 未来任意指标),值是该指标**通用引擎**输出的**事实/规则 JSON**(**无任何判断**):
  - 公共:`kind`(`tabular`/`catalog`)、`summary`、`field_stats`(各字段分布/数值摘要)。
  - **tabular(如 CHR)**:`field_stats` 就是各列的真实分布/数值。
  - **catalog(如 kpiTree)**:另有 `rules`(各 KPI 的 `formula`/阈值/定义)、`counter_index`(计数器 → 用到它的 KPI/公式/阈值)。**kpiTree 只有定义,没有实测值。**
  - **引擎不下判断、也不替你做"故障树匹配";投影 + 判断全是你的活。**

## 你要做什么
遍历子树,对**每条判断条件**先分清依据:**CHR 类**(点名某列/取值)→ 到 `tabular` 的 `field_stats` 取值算成立/不成立;**话统计数器类**(`N./L.xxx`)→ 需实测值而 kpiTree 只有定义 → 用 `counter_index`/`rules` 取阈值/公式作背景但**如实判"数据不足"**。再回溯到根 → 输出根因 + 判断依据。详细规则见 `references/rca_rules.md`(务必先读)。

**三条铁律(最重要)**:
1. **只用真实事实**:evidence 的 `actual` 逐字引用引擎给的值/计数(如 `RrcReject = 4/10`);**禁止**引入引擎没给过的计数器/数字;**精确匹配**(要 `0x810D176C` 就不能拿相近的 `0x810D176B` 顶)。
2. **话统计数器无实测值是常态** → 该条件如实**数据不足/未判定**,不得当成立或不成立;**不拿 CHR 分布或 `field_stats` 硬替话统阈值**。
3. 一条路径算根因,要求**路径上每个带判断条件的节点都"成立"**;**没有完全证实的路径就如实输出"未找到充分证据的根因"(`[]` + undetermined),绝不硬凑编值编根因**。

> 聚合数据里可能并存多种失败模式 → 多根因合理,但**每个都要完整证实**,并**去重 + 按支持度排序**。
> **口径一致**:你的文字总结必须和落盘的 `rca.json` 一致——落盘是 `[]`/数据不足,就**别**在叙述里说"发现了 N 条根因";把"数据不足"的节点当成根因列出来,就是硬找。

## 输出契约
```json
[
  {"Root_cause":"根因节点名称",
   "Fault_tree_path":["父节点1","父节点2","根因节点"],
   "evidence_path":[
     {"node":"父节点1","condition":"<逐字判断条件>","actual":"<实际数值>","judgment":"<代入比较 → 成立/不成立>"},
     {"node":"根因节点","condition":"...","actual":"...","judgment":"..."}
   ]}
]
```
每条 evidence 必须把 **规则(`condition`,逐字取自故障树)+ 实际值(`actual`,逐字引用引擎事实)+ 怎么判断与结论(`judgment`,你现在代入比较算出,可为"数据不足")** 写清楚,**不能只写一句裸条件**。

## 分工(重要)
- **引擎只把数据查清楚 / 把规则摆出来**(事实:`field_stats`;catalog 另有 `rules`/`counter_index`),**不下任何判断、不做故障树匹配**。
- **投影 + 判断全在你这一步**:把引擎的真实值代入故障树条件 → 比较 → 算成立/不成立;话统计数器无实测值就如实数据不足;再做路径回溯、逐节点取证、处理子树的不规整。两边都不许编。
