# 各步骤向用户输出的固定格式

流程各步向用户展示的模板。方括号里是要填的内容。

## 步骤 1：格式校验

通过：

```
格式校验通过！
- 发现 X 个网元：网元A、网元B

网元A：
  - CONFIG/ 文件数：X
  - CMD/ 文件数：X
  - LOG/ 文件数：X
```

不通过：

```
格式校验未通过，发现以下问题：

[X] 问题 1：网元 [网元名] 下没有任何数据目录
   修复方法：该网元文件夹下至少需要存在 CONFIG/、CMD/、LOG/ 中的一个目录
```

## 步骤 3：数据探索预检

```
数据探索预检：

基于您描述的"[配对规则]"，我扫描到以下数据：
  - 网元A：[关键数据项]
  - 网元B：[关键数据项]

可形成的配对：
  - 配对1：[条件] → [网元列表]
  - 配对2：[条件] → [网元列表]

请确认这个配对关系是否符合预期？
  [OK] 符合，继续
  [修改] 不符合，修正规则
```

## 步骤 4：确认判断方法

```
理解总结：

故障树节点：[节点名称]
判断方法：
  1. 条件 A：[具体条件描述]
     - 数据来源：CONFIG/CMD/LOG
     - 匹配规则：[正则/关键字/数值比较]
  2. 条件 B：[具体条件描述]
     - 数据来源：CONFIG/CMD/LOG
     - 匹配规则：[正则/关键字/数值比较]

边界条件澄清（请明确选择）：
  [A] [边界条件描述A] → ?
  [B] [边界条件描述B] → ?

命中条件：[A 且 B] 或 [C]

涉及网元：[网元A、网元B]

请确认判断方法理解是否正确？
  - 输入 [OK] 确认，继续下一步
  - 输入 [修改建议]，我将调整判断方法描述
```

## 步骤 6：数据定位确认

```
数据定位确认：

已找到以下关键配置项：
  [网元A] [配置项] → [值] ✓
  [网元B] [配置项] → [值] ✓

请确认数据定位是否正确？
  [OK] 正确，继续诊断
  [修改] 定位有误，修正脚本
```

数据缺失时：

```
未在数据文件中找到 [命令名] 的输出。

请提供数据位置：
- 该命令输出在哪个文件？
- 或者直接粘贴相关数据片段
```

## 步骤 7：故障诊断

```
诊断结果：

【网元名】
  [SUCCESS] 检测到 X 个符合条件的情况
     - 证据1：...
     - 证据2：...
  或
  [OK] 未检测到符合条件的情况
```

## 步骤 8：确认诊断结果

```
诊断结果已输出，请确认结果是否正确？
  - 输入 [OK] 确认结果，继续下一步
  - 输入 [修改建议]，我将调整脚本逻辑
```

## 步骤 9：方案验证

```
方案验证：

解决方案：[用户提供的解决方案]

验证结果：
  [OK] 方案有效
     - 原因：...
  或
  [WARN] 方案需调整
     - 问题：...
     - 建议：...
```

## 步骤 10：打包前检查

```
打包前检查：

1. 数据目录文件检查：
   - [OK] 测试数据目录存在且包含有效文件
   - [ERROR] 数据目录缺失或为空

2. 判断方法文档检查：
   - [OK] 判断方法.md 已生成且包含必填字段
   - [ERROR] 判断方法.md 缺失或必填字段不完整

3. Python 脚本检查：
   - [OK] fault_check_[故障节点名].py 已生成
   - [OK] 脚本使用 search_config.py 通用解析模块
   - [ERROR] 脚本缺失或未复用通用模块

4. 契约检查（必须全绿）：
   - 命令：python scripts/check_contract.py <打包目录> --strict
   - [OK] 全部 PASS
   - [ERROR] 有 FAIL/WARN，按输出的修法逐项修完重跑，绿了才许打包

请确认以上检查项是否全部通过？
  [OK] 全部通过，开始打包
  [修改] 存在问题，修正后再打包
```

## 步骤 11：打包完成

```
📦 打包交付完成！

压缩包路径：skills/datacom-fault-tree-tester/output/[故障节点名]_[yyyyMMdd-HHmmss].zip

解压后包含：
  - 判断方法.md          # 符合规范的判断方法文档
  - 判断方法_规范.md     # 规范文档（始终包含）
  - 测试数据/           # 用户输入的测试数据（如有）
  - fault_check_*.py    # 判断脚本（如有）
  - scripts/            # 脚本 import 到的 search_*.py（一律随包）加其他改动脚本
  - 执行记录.md         # 本次执行过程完整记录
```
