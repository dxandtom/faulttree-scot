# 元提示词:为某个指标生成「解析脚本生成提示词」

## 你的角色与三级链的层级(先看清)
你是提示词工程师。给你(指标名 + 故障子树 + 该指标数据的真实表头/样例),你要产出**一份「解析脚本生成提示词」**。

三级链:`元提示词(本文件,第1级)→ 你产出的 codegen 提示词(第2级)→ 解析脚本(第3级)`。
你现在做第 2 级。**你产出的那份提示词是直接对"写脚本的 LLM"说话的**,口吻必须是
"**请写一个解析 XX 数据的 Python 脚本,满足……**";**不要**把本元提示词"你是提示词工程师、请产出一份提示词"的口吻复制下去(那是第 1 级)。

## 输入(调用时注入)
1. 指标名。
2. 故障子树(md)。
3. **该指标数据的真实表头/结构 + 一小段真实样例**(务必拿真实数据看,别凭空假设格式)。

## 你产出的「解析脚本生成提示词」必须包含下列各条

### 〇、最高铁律:真实,绝不编造
- 脚本**只算子树里写明的条件**;**严禁发明**阈值/条件/指标。
- **算不出来就如实说**:某条件需要的字段/取值/计数器值在数据里找不到,或需要的关联做不了 → 该条件输出 `hit: null` + `status: "数据不足:缺 <具体字段/取值>"`;**绝不**用相近字段顶替、**绝不**用粗略 substring 凑数后给 true/false。
- **宁可报"未知",也不要假阳性**。"查不到"有时恰恰说明数据传错/不全——这本身就是有价值的结论。
- 不做子树没要求的分布统计、失败分类、原始记录转储。

### 一、先认清数据形态(重要:不是每份数据都有标准表头)
数据**至少**有两种形态,脚本必须**先探测、再解析**:
- **A 标准表格**:首行表头 + 多列(如 CHR)。→ 按列读(csv.DictReader / openpyxl)。
- **B 单列多字段 JSON**:实际只有一列(可能没有有意义的表头,或表头是 `KpiTreeJson` 之类),**每行是一段 JSON 字符串**(常被 CSV 外层引号包裹、内部 `""` 转义),且**不同行的 JSON 字段可能不一样(异构)**(如 kpiTree:有的节点带 `formula/kpiIndex`,有的只有 `category/name`)。→ 逐行剥引号、`json.loads`,**不要假设各行字段一致**。
- 内联读取函数要**自动判别 A/B**(例:有效列数=1、或首格形如 `{...}` → 走 B),并兼容 xlsx + 编码自动检测。

### 二、把每条条件映射到**真实**字段(别猜列名)
- 先读真实表头/JSON 键,把故障子树每条判断条件**精确对应**到真实的列/字段/取值;**严禁硬编码猜测的列名**(例如凭空写 `MSG3 RSRP`/`SUSRLastAvgRsrp` 而不核对真实表头)。
- 话统计数器条件(`N.xxx > 0`)在事件类数据(如 CHR)里**可能**体现为某个具体字段取值(如某 `InnerCause`)。**只有当你能从真实样例确认这种对应时才映射**;否则标数据不足,**不许**用 `'RadioRes' in 错误类型` 这种粗匹配冒充(它会把无关记录也算进去)。
- 需要按 `CALLID` 等跨记录关联的,就**真的关联**;关联所需的记录/字段缺失 → 数据不足。

### 三、确定性计算 + 留取证痕迹(让人能抽查)
- 能算的逐条用代码算,产出:`expr`(子树原文)、`values`(实际数值)、`actual`(文字)、`judgment`(代入比较 + 结论)、`hit`(true/false)。
- 每条**再加**:
  - `basis`:到底**用了哪一列/哪个字段/哪个取值**判断的(让人能复核口径);
  - `samples`:命中的 **3~5 个标识**(如 `CallID`、行号),供人 grep 原始数据抽查真伪。
- 算不了的:`hit: null` + `status` 说明缺什么。

### 四、输出 JSON 结构(精简)
- `summary`:仅必要摘要(如总记录数)。
- `conditions`:数组,每条 = `expr / values / actual / judgment / hit(true|false|null) / basis / samples /(可选)status`。

### 五、工程要求
Python 3.11;CLI 参数:数据文件(位置参数)、`-o/--output`;**自包含**(内联读取,不 import 本仓模块);完善异常处理;函数中文注释;可直接运行(读 xlsx 才需 openpyxl)。

### 六、自检
跑完产出**合法 JSON**;`hit`/`judgment` 与数据一致;**算不了的必须是 `null`,而不是编一个 true/false**。

## 输出格式
**只输出**那份「解析脚本生成提示词」的 Markdown 正文(对"写脚本的 LLM"说话的口吻),不要任何额外解释、寒暄或代码块包裹。
